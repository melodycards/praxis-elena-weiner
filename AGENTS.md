# Dauerhafte Projektregeln

Diese Regeln gelten für alle zukünftigen Aufgaben in diesem Praxis-Projekt:

- Ausschließlich Dateien innerhalb von `/Users/tmr/Documents/Arzt` bearbeiten.
- Das Projekt oder Repository `melody-cards` niemals verändern.
- Das Projekt oder Repository `autodienst-schwanheim` niemals verändern.
- Jede vom Benutzer gewünschte Änderung vollständig umsetzen.
- Nach der Umsetzung prüfen, dass die Website fehlerfrei baut.
- Erst nach erfolgreicher Prüfung alle fertigen Änderungen automatisch committen.
- Anschließend den fertig geprüften Stand automatisch auf den Branch `main` von `https://github.com/melodycards/praxis-elena-weiner.git` pushen.
- Keine Zwischenstände pushen; immer nur den vollständig umgesetzten und erfolgreich geprüften Stand veröffentlichen.
- Nach einem erfolgreichen Push kurz bestätigen, dass GitHub aktualisiert wurde und Vercel dadurch automatisch neu deployt.
